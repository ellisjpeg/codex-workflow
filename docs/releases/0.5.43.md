# Workflow 0.5.43

This is an alpha maintenance update, published as a regular Latest release. Workflow is an independent community project, not affiliated with or endorsed by OpenAI.

## What changes

- Public setup installs Workflow into the existing Codex app. It no longer creates or opens Codex Workflow Staging.
- Staging remains an explicit developer tool for testing unfinished features. Its helpers are excluded from the updater asset; no staging app is distributed.
- Source checks, exact-build preflight, installation confirmation, backups, recovery and verification before relaunch remain in place.
- The GitHub README is shorter, adds illustrations matching the original banner, and links to detailed operating notes. Pull requests are not accepted; bug reports and feature ideas remain welcome.

The Sidebar, Composer, Conversation and Usage features from Alpha 1 are unchanged. This update does not change model selection, reasoning, permissions or request contents.

## Compatibility

Use macOS with Codex Desktop **26.908.40834, build 8881**, and Node.js **24.15+ in the 24.x line, or 26+**. The existing native feature evidence covers Apple Silicon; Intel-native acceptance is not established. Do not force an unsupported Codex build with `--allow-version`.

## Install or manually upgrade

Use a fresh checkout of the published release:

```sh
git clone --branch v0.5.43 --single-branch https://github.com/ellisjpeg/codex-workflow.git codex-workflow-alpha-1
cd codex-workflow-alpha-1
npm ci --engine-strict
npm run setup -- --no-auto-repair
```

Setup checks compatibility and asks before installing into Codex. Save your work before agreeing to quit Codex. Existing installations use the guarded reapply path. Keep this checkout for status, recovery and removal.

Installation modifies the local Codex app bundle and replaces its vendor signature with an ad-hoc signature. The command disables automatic repair when it installs; an already-current setup does not change existing preferences. There is no separate alpha update channel. Compatible installations can receive this version through Update Workflow.

The reduced updater archive is not the source/test checkout needed by setup. Developer staging is available only through an explicit `npm run staging` command in the full source checkout. The already-published `v0.5.42` source still has its original staging-based setup; use the new tag for the direct installation flow.

## Verification scope

Local source checks passed all 245 tests, including fresh-install/reapply orchestration, cancellation and failure guards, and updater packaging without staging helpers. The guarded reapply dry-run passed without warnings. The active runtime files are unchanged from `0.5.42`. A live `0.5.43` installation, removal and update/relaunch roundtrip were not exercised for this release; fixture and dry-run results do not establish those native checks.

## Status, recovery and removal

From the retained checkout, inspect the installation first:

```sh
npm run status --silent
```

Quit Codex before removal, then restore the verified app backup:

```sh
npm run uninstall:patch
```

If status identifies a recoverable interrupted transaction, quit Codex and run `npm run recover:patch` first. Stop on unsafe journals, missing backups or unsupported states. Removal restores original app contents with an ad-hoc signature; reinstall the official Codex app to restore its vendor signature.
